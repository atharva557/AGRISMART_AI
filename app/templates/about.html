About AgriSmart AI

Smart Agricultural Diagnostics & Advisory System for precision farming

Overview

AgriSmart AI is a comprehensive agricultural intelligence platform. It combines AI-powered disease detection with four precision advisory modules to help farmers and agronomists make informed decisions.

The system prioritizes transparency and responsible use by clearly labeling experimental results, showing confidence scores, and providing detailed limitations for each module.

Advisory & Intelligence Modules (A–E)

Open dashboard
A

Crop Recommendation

EXPERIMENTAL

Random forest classifier ranks top three crop labels using seven soil/weather features (Nitrogen, Phosphorus, Potassium, temperature, humidity, pH, rainfall).

Dataset: 2,200 rows from Kaggle crop recommendation dataset

Test Macro-F1: 0.9909

Limitation: Dataset-scoped; units and periods unresolved; not validated for field suitability

B

Irrigation Advisory

TRANSPARENT CALCULATION

FAO-56 style soil water balance calculation provides irrigation timing and volume recommendations based on root-zone depletion.

Method: Soil water balance with allowable depletion

Inputs: Soil moisture, field capacity, wilting point, crop coefficient, weather forecast

Limitation: Requires calibrated soil measurements; does not actuate pumps; assumed rain effectiveness

Try it now
C

Weather Intelligence

LIVE DATA & GEOLOCATION

Validates Open-Meteo forecasts with one-click geolocation and applies threshold-based alerts for cold, heat, rain, wind, humidity, and moisture conditions.

Data Source: Open-Meteo Forecast API with Browser Geolocation

Caching: 6 hours in-memory to reduce external API requests

Limitation: Generic thresholds; forecasts are predictions rather than direct sensor observations

Try it now
D

Sustainability Scoring

TRANSPARENT FORMULA

Compares water, electricity, and nitrogen intensity between baseline and current practices with a yield retention check.

Formula: Weighted component sum (water 40%, electricity 30%, nitrogen 30%)

Safeguard: Score capped at 50 if yield retention falls below 95%

Limitation: Comparative analysis only; does not prove software-caused savings or carbon impact

Responsible Use Guidelines

Always consult experts: All predictions and recommendations should be verified by qualified agronomists before field implementation.

Verify confidence: Disease detection predictions below 75% confidence require expert confirmation.

Understand limitations: Module A is dataset-scoped, not field-validated. Irrigation advice requires calibrated sensors.

Local context matters: Weather thresholds and crop recommendations need local validation for your region.

Not for autonomous control: This system provides decision support only. Do not automate farming operations based solely on these recommendations.

Technical Architecture

Backend: Python Flask 3.1.3 (Modular Blueprint Monolith)

Computer Vision ML: ConvNeXt-Tiny (384 px) with ResNet-18 fallback via PyTorch & Timm

Advisory ML: Scikit-learn Random Forest Classifier with pinned SHA256 checksums

Generative AI: Google Gemini 1.5 Flash (`google-genai`) with grounded session memory & deterministic fallback

Multilingual Engine: Deep-Translator with LRU caching and thread-serialized backoff

Frontend: HTML5, Tailwind CSS, Vanilla ES6+ JavaScript bundled with Webpack 5

API Contract: Versioned JSON envelope with strict data validation & evidence tracking
